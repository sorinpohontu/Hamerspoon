# Roadmap

Ideas for making the Spoons more useful and easier to set up. These are possibilities, not promises or release dates; priorities may change.

## ScheduledTask

- Retry failed tasks automatically.
- Keep a history of recent runs.
- Support dependencies and chains between tasks.

## DiskTemp

- Add Fahrenheit temperature conversion.

## All Spoons

- Make documentation available in Hammerspoon's built-in help viewer.
- Make installation easier.
